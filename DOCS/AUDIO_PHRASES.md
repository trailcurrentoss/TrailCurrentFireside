# Audio Alarm Phrases

The device speaks pre-recorded PCM clips through the on-board ES8311 audio
codec when alarms fire. The clips are baked into firmware at
`main/audio_assets.c` (no SPIFFS / runtime TTS), and generated by
`tmp/gen_tts_assets.py` using ChatterboxTTS via the local ComfyUI instance.

Format: 16-bit signed LE PCM, mono, 22050 Hz (matches `main/audio.c`'s
`esp_codec_dev` sample-rate config — no runtime resampling).

## Current phrases

| Enum (`audio_phrase_t`)         | Spoken text                                        | Triggered when… |
|---------------------------------|----------------------------------------------------|------------------|
| `AUDIO_PHRASE_BATTERY_LOW`      | "Battery is low."                                  | Reserved / not currently wired — kept for future per-mode battery warn. |
| `AUDIO_PHRASE_BATTERY_THRESHOLD`| "Battery level below threshold."                   | Rising edge of a configured battery-critical alarm in `alarms.c`. |
| `AUDIO_PHRASE_CO_DANGER`        | "Carbon monoxide detected. Ventilate immediately." | Rising edge of CO **alarm** (`s_co_alarm`). |
| `AUDIO_PHRASE_CO_WARNING`       | "Carbon monoxide warning."                         | Rising edge of CO **warn** or CO ppm ≥ 70 without full alarm. |
| `AUDIO_PHRASE_AIR_UNHEALTHY`    | "Air quality alert. Consider ventilating."         | `overall_aq_class() == AQ_BAD` transitions from false to true. |
| `AUDIO_PHRASE_CONN_LOST`        | "Connection lost."                                 | MQTT broker down for ≥ 30 s (see `MQTT_DOWN_GRACE_SEC` in `vars.c`). |
| `AUDIO_PHRASE_CABINET_ALARM`    | "Cabinet alarm."                                   | Sensor label matches `cabinet` or `cupboard`. |
| `AUDIO_PHRASE_DOOR_ALARM`       | "Door alarm."                                      | Sensor label matches `door`, `hatch`, or `entry`. |
| `AUDIO_PHRASE_WINDOW_ALARM`     | "Window alarm."                                    | Sensor label matches `window`. |
| `AUDIO_PHRASE_COMPARTMENT_ALARM`| "Compartment alarm."                               | Sensor label matches `compartment`, `bay`, or `storage`. |
| `AUDIO_PHRASE_REFRIGERATOR_ALARM`| "Refrigerator alarm."                             | Sensor label matches `fridge`, `refrigerator`, or `freezer`. |
| `AUDIO_PHRASE_WATER_ALARM`      | "Water alarm."                                     | Sensor label matches `water`, `tank`, or `leak`. |
| `AUDIO_PHRASE_MOTION_ALARM`     | "Motion alarm."                                    | Sensor label matches `motion`, `movement`, or `pir`. |
| `AUDIO_PHRASE_SENSOR`           | "Sensor triggered."                                | Fallback when no sensor-label keyword matches (see `pick_sensor_phrase()` in `vars.c`). |

Category keyword mapping is defined in `pick_sensor_phrase()` at
[main/vars.c](../main/vars.c). Order matters — more specific keywords are
checked first.

## Voice reference

Current bake uses `common_voice_en_42710088.mp3` (a female voice from Mozilla
Common Voice) as the ChatterboxTTS voice-cloning reference. Any 10-15 s clip
of clear speech works; expressive, non-monotone samples produce more natural
output. Prior bakes used `MatthewM.mp3` (a more expressive male voice).

Voice-reference files live in `/media/dave/extstorage/ComfyUI/input/`.

## Regenerating

```bash
python3 tmp/gen_tts_assets.py
```

Requires:
- ComfyUI running at `http://localhost:8188` with the ChatterboxTTS custom
  node loaded.
- `ffmpeg` on `PATH` (used to strip silence, loudness-normalize, and convert
  FLAC → raw PCM).
- The voice-reference file specified by `VOICE_REF` present in
  `/media/dave/extstorage/ComfyUI/input/`.

The script is idempotent — it replaces `main/audio_assets.c` and
`main/audio_assets.h` wholesale from the `PHRASES` list at the top. To change
what a phrase says, edit that list and re-run. To add a new phrase, add a
tuple and also add its trigger call to `vars.c` / `alarms.c` (the enum will
be extended automatically). To rename an enum, update all `AUDIO_PHRASE_*`
references in `main/`.

Per-clip generation parameters (all in `gen_tts_assets.py`):
- `exaggeration = 0.6` — slight urgency for alarm context.
- `temperature = 0.7` — moderate variability.
- `flow_cfg_scale = 0.7`, `cfg_weight = 0.5` — model defaults for coherence.
- Loudness normalized to `I=-16 LUFS, TP=-1.5 dB` so all clips play at
  consistent level regardless of source phrase.

The seed is randomized per clip, so two runs produce audibly different
takes even from the same phrase text — bake once, listen through, re-run
if any clip lands poorly.
